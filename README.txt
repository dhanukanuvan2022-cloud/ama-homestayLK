Ama HomeStay website
1. Open js/main.js and replace 94XXXXXXXXX (CFG.wa) with the host's WhatsApp number, e.g. 94771234567 (no + and no leading 0).
2. Edit the ROOMS list in js/main.js to set real room names and USD prices. CFG.rate sets the LKR conversion.
3. Upload the whole folder to any web host (Netlify, GitHub Pages, cPanel) and open index.html.
Note: the chat assistant uses built-in answers (Sinhala + English). The Claude-powered replies only work inside claude.ai; to use an AI on your own host you need a small backend with an API key.
